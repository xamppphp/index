Теория Практика Скачать

JavaScript / SEO

1. Охарактеризуйте основные понятия, связанные с оптимизацией веб-приложений. (оптимизатор, целевая аудитория, релевантность, поисковая система, семантическое ядро, SEO).
Оптимизатор — специалист, осуществляющий продвижение сайта, т.е. предпринимающий определенные действия с тем, чтобы сайт стал известен максимальному числу пользователей всемирной паутины, в особенности, целевой аудитории.
Целевая аудитория — группа интернет пользователей, на которую сфокусировано содержание сайта.
Релевантность — степень соответствия выдачи поисковых результатов ожиданиям пользователя, обратившегося с данным запросом.
Поисковая система — аппаратно-программный комплекс, который предназначен для осуществления функции поиска в интернете, и реагирующий на пользовательский запрос выдачей списка на информационные источники, осуществляющейся по релевантности.
Семантическое ядро — набор слов и словосочетаний, отражающих тематику и структуру сайта.
SEO (поисковая оптимизация) — комплекс мер для поднятия позиции сайта в результатах выдачи поисковых систем по определённым запросам пользователей.
2. Раскройте историю развития отношений поисковых систем и SEO-специалистов
Этап 1. Изначально для целей поиска информации был предназначен мета-тег Keywords. Использовался для указания ключевых слов, но не позволял сортировать результаты по важности.
Этап 2. После этого появился настоящий, полнотекстовый поиск. Поисковики стали оценивать текст материала, а также html-оформление. Поисковые системы начали сортировать результаты по релевантности. Оптимизаторы ответили на это появлением нового направления деятельности seo-копирайтинга.
Этап 3. Принципиальный шаг к решению этой проблемы совершила компания Google, введя понятие ссылочной цитируемости. Основа алгоритма: лучше страница — та страница, на которую больше ссылаются другие сайты. Учитывалось количество и авторитетность ссылающихся ресурсов. Это улучшило качество поиска, но привело к развитию индустрии по продажи ссылок.
Этап 4. Поисковые системы стали отслеживать поведение пользователей на ресурсе. Сколько времени провёл на сайте, сколько страниц просмотрел. Но эти факторы легко поддаются накрутке, что делает их ненадёжными.
Этап 5. Очередным принципиальным шагом стало использование в алгоритмах элементов ИИ, которые позволяют «машине» видеть «глазами человека».
3. Опишите какие сайты целесообразно продвигать, а какие нет.
Целесообразность продвижения сайта зависит от его потенциала для привлечения целевой аудитории, технической готовности, конкурентной среды и соответствия бизнес-целям.
Целесообразно: Интернет-магазины, Сайты услуг, Информационные порталы, Образовательные платформы.
Нецелесообразно: Сайты-однодневки, Личные страницы без коммерческой цели, Сайты с незаконным контентом, Проекты с очень узкой аудиторией (если нет рекламного бюджета).
4. Опишите основные составляющие внутренней оптимизации сайта.
Тексты — уникальные, полезные, с ключевыми словами.
Заголовки (H1, H2, H3) — логическая структура.
Мета-теги — title (заголовок в выдаче), description (краткое описание).
URL — понятные для человека адреса (/kupit-iphone).
Внутренняя перелинковка — ссылки между страницами своего сайта.
Картинки — оптимизированы по весу, с alt-текстом.
Скорость загрузки — сжатие кода, кэширование, современные форматы картинок.
5. Раскройте понятие внутренней перелинковки сайта, ее элементы, приведите примеры
Внутренняя перелинковка — система ссылок между страницами одного сайта. Помогает поисковику понять структуру сайта, распределяет вес страниц, увеличивает время на сайте.
Элементы: ссылки в тексте (контекстные), навигационные меню, «хлебные крошки», карта сайта.
Пример: В статье о варке кофе → ссылка на страницу с выбором кофемашины.
6. Опишите виды перелинковок, приведите примеры.
Перелинковкой сайта называют связывание страниц одного сайта или разных ресурсов гиперссылками.
Сквозная перелинковка — все страницы сайта ссылаются друг на друга. В этом случае у всех документов одинаковый вес. Схема идеально подходит для небольших сайтов, где все страницы примерно одинаковой важности.
Иерархическая перелинковка — удобно с точки зрения логики. Но страницы-листочки на самом нижнем уровне иерархии получают очень мало веса, что для продвижения нежелательно.
Схема «плотного связывания» — связывание страниц не через сквозные меню (или не только через меню), но и через ссылки в тексте материалов. Пример — Википедия. Читаешь статью, а половина слов — ссылки на другие статьи, посвященные этому слову/явлению.
7. Раскройте виды текста ссылок и меню, приведите примеры.
Анкерный текст — ключевое слово в тексте ссылки. Поисковая система расценивает этот текст как короткое и прямое описание темы страницы, на которую стоит ссылка.
Виды анкоров: Прямой (точный) анкор — содержит точное вхождение ключевого слова или фразы; Частичный (непрямой, разбавленный) анкор — включает ключевую фразу в составе более длинного текста; Брендовый анкор — содержит название бренда или компании; Разбавленный (общий) анкор — состоит из общих слов и фраз; Указательные (безанкорные) анкоры — не содержат ключевых слов, в качестве анкора используются URL-адреса.
Меню сайта — сквозной блок ссылок; в нём лучше всего перечислить основные разделы сайта, употребив при этом ключевые слова. Виды меню: «хлебные крошки», «облако тегов», «карта сайта», бургер-меню.
8. Опишите внешнюю оптимизацию сайта, типы внешних ссылок.
В основе поиска всегда лежит релевантность документа — насколько полно он отвечает запросу. В связи с этим оптимизаторы наплодили бесконечное количество идеально релевантных текстов, чем сделали нормальный поиск невозможным.
Типы внешних ссылок:
Естественные — вас порекомендовали на форуме, или блогер написал заметку. Такие ссылки появляются без вашего участия и действительно характеризуют полезность ресурса.
Покупные ссылки (SEO-ссылки) — размещаются на других сайтах за соответствующую оплату. Делятся на: «вечные» и арендные.
SEO-ссылка — ссылка, проставляемая исключительно с целью улучшить позиции сайтов в поисковых системах. Прямых посетителей с ней нет.
Анкорные и безанкорные — определяется ссылочным текстом (анкором).
Прямые ссылки через редирект — полностью передают вес от донора к акцептору.
9. Охарактеризуйте счетчик значимости страницы PageRank и его замену.
PageRank показывает, насколько данный документ авторитетен для Google. Регулировать числовое значение PR любой web-страницы можно путем передачи веса с помощью ссылок, которые ведут на нее со страниц других web-сайтов и с внутренних web-страниц этого же web-сайта.
Как работает: учитываются 3 фактора: количество и качество внешних ссылок; количество исходящих ссылок на каждой странице; PageRank каждой ссылающейся страницы.
Счетчик был убран. PageRank сам по себе остался и влияет на ранжирование, но Google скрыл сам счетчик. После отмены счетчика PR у оптимизаторов не появилось аналогичного показателя, по которому можно было бы определить значимость страницы.
10. Охарактеризуйте тИЦ и ИКС, понятие, задачи, особенности
тИЦ — тематический индекс цитирования, который определялся на основании количества и качества ссылающихся сайтов. Появился в 1999 году. Основной задачей тИЦ Яндекса было определение достоверности интернет-ресурсов, а также позиции сайта в той или иной категории. За 20 лет тИЦ устарел, он уже не отражает действительности. В 2020 году Яндекс отменил тИЦ.
ИКС (индекс качества сайта) — основная цель введения — определение востребованности интернет-ресурсов у пользователей. Новая технология по расчёту индекса качества принципиально отличается от старой. Она зависит от множества различных факторов: уникальности контента; востребованности; удовлетворенности посетителей; работы с соцсетями; количества и качества ссылок; доверия пользователей.
11. Дайте понятия: индексация сайта и краулинговый бюджет.
Важной составляющей при поисковой оптимизации является работа с внутренними факторами. К таким факторам относят управление индексацией ресурса — настройка его взаимодействия с роботами поисковых систем.
Индексация сайта — процесс обхода страницы веб-ресурса поисковыми роботами и внесения полученной информации в базу поисковых систем. Для того чтобы ресурс появился в выдаче Яндекса или Google, необходимо, чтобы он был просканирован и добавлен в их индекс.
Краулинговый бюджет — это количество страниц на сайте, которое поисковый робот (Googlebot) может и успевает просканировать за один визит или за определённый промежуток времени. Он ограничен, чтобы не перегружать сервер сайта.
Googlebot — поисковой робот компании Google, используемый для сканирования.
12. Способы управления краулинговым бюджетом.
Для того чтобы оптимизировать расход краулингового бюджета необходимо корректно управлять индексацией сайта — давать возможность индексировать роботам только те страницы, которые важны для продвижения ресурса.
Способы управления:
- Закрывать от индексации мусорные страницы (robots.txt, noindex).
- Улучшать скорость загрузки сайта.
- Делать понятную структуру URL.
- Использовать карту сайта (sitemap.xml).
- Убирать дубли страниц.
13. Опишите назначение файла robots.txt, директива User-agent.
Robots.txt — файл ограничения доступа к содержимому сайта роботам на HTTP-сервере. Файл должен находиться в корне сайта (путь /robots.txt).
Назначение файла robots.txt — сообщить поисковым роботам, какие страницы сайта они могут индексировать, а какие нет.
Директива User-agent в файле robots.txt указывает для какой поисковой системы и какого конкретного робота прописываются инструкции. Пример: User-agent: Yandex (указывает директивы для всех роботов Яндекса).
14. Опишите назначение файла robots.txt, директивы Allow и Disallow.
Robots.txt — файл ограничения доступа к содержимому сайта роботам на HTTP-сервере. Файл должен находиться в корне сайта (путь /robots.txt). Назначение — сообщить поисковым роботам, какие страницы сайта они могут индексировать, а какие нет.
Директива Disallow в файле robots.txt означает запрет к индексации страницы, раздела или файла.
Директива Allow в файле robots.txt разрешает индексацию указанных страниц, разделов или файлов сайта.
15. Назначение пагинации на сайте. Проблемы с пагинацией при SEO
Пагинация на сайте — навигационный ссылочный блок, который облегчает для пользователей переход и просмотр товарных позиций, страниц каталога, публикаций. Постраничная навигация используется для улучшения юзабилити сайта и увеличения скорости загрузки страницы. Пагинация выполняется на скриптовом языке PHP, т.к. он сегодня чаще всего используется для разработки web-приложений.
Проблемы с пагинацией при SEO: поисковики могут применить штрафные санкции за повторение контента; товарные позиции долго индексируются; если контент схож, поисковику трудно определить релевантную страницу; значимость страниц распыляется и теряется.
Способы решения: закрыть пагинацию для индексации с помощью мета-тега NOINDEX (на каждой странице, кроме первой) или через файл robots.txt, либо использовать страницу «Смотреть все» и тег CANONICAL.
16. Понятие семантического ядра сайта. Классификация поисковых запросов.
Семантическое ядро — набор слов и словосочетаний, отражающих тематику и структуру сайта.
Классификация поисковых запросов:
- Навигационные запросы — пользователь ищет какой-то конкретный сайт или фирму.
- Информационные запросы — цель получить информацию. Пример: «Достопримечательности Ярославля».
- Транзакционные запросы — посетитель хочет выполнить какое-то действие. Пример: «снять квартиру в Москве».
- Нечеткие запросы — например, слово «кондиционер». Непонятно, что имел в виду человек. Такие запросы в семантическом ядре стоит избегать.
- Многозначные запросы — слова-омонимы, имеющие 2 абсолютно разных значения (зАмок или замок).
- Геозависимые и геонезависимые запросы — классический пример: запросы на тему «птица».
17. Классифицируйте запросы по частотности, раскройте особенности их использования для оптимизации.
Высокочастотные запросы. Плюс: большой приток посетителей. Минусы: ВЧ запросы являются очень размытыми, нечеткими; конверсия и финансовая отдача будут очень низкими; топ по ВЧ запроса забит «монстрами», молодому сайту конкурировать невозможно; на попадание в первую десятку может уйти до 2 лет. Попытка сразу ориентироваться на ВЧ запросы может привести к использованию бюджета без достижения результатов.
Среднечастотные запросы. Именно на них следует ориентироваться большинству коммерческих сайтов. Они уже более конкретны и обеспечивают неплохую конверсию. Конкуренция тоже посильная.
Низкочастотные запросы. В SEO есть термин «длинный хвост» или «длинный шлейф» запросов. Именно 70-80% посетителей приходят на сайт по низкочастотным запросам.
18. Раскройте алгоритм сбора ключевых слов с помощью Яндекс.Вордстат.
1) Выделение направлений, по которым будет продвигаться сайт. Важно определить, какие товары и услуги будут продвигаться в поисковой выдаче Яндекса или Google.
2) Сбор ключевых слов, анализ похожих запросов и поисковых подсказок (сбор семантических).
3) Парсинг частотности, отсев «пустых» запросов — проверяем, сколько раз определенный запрос искали. Для этого перед каждым словом ставим «!».
4) Кластеризация (группировка) запросов — объединить похожие по смыслу запросы в кластеры, а затем определить, на какие страницы они будут продвигаться.
5) Распределение запросов по страницам сайта.

PHP Теория

1. Что такое PHP и как он работает?
PHP (Hypertext Preprocessor) — это скриптовый язык программирования общего назначения, который специально создан для веб-разработки. Код PHP выполняется на стороне сервера, а не в браузере пользователя. Сервер обрабатывает PHP-код и возвращает готовый HTML-документ. PHP-код встраивается в HTML с помощью тегов <?php ... ?>. Основные особенности: бесплатный, кроссплатформенный, поддерживает большинство серверов (Apache, Nginx, IIS) и баз данных (MySQL, PostgreSQL, SQLite).
2. Переменные в PHP: определение и правила именования
Переменная в PHP — это именованный контейнер для хранения данных. Правила: начинается с символа $, затем имя; имя может содержать буквы, цифры и знак подчеркивания; имя не может начинаться с цифры; регистр важен ($name и $Name — разные переменные). Тип данных присваивается автоматически в зависимости от значения. Примеры: $age = 25; $name = "Анна"; $price = 19.99; $isActive = true; $colors = array("красный", "синий", "зеленый").
3. Типы данных в PHP
PHP поддерживает следующие типы данных: целые числа (int) — 1, 2, 100; числа с плавающей точкой (float) — 1.5, 3.14; строки (string) — "Привет", 'мир'; булев тип (bool) — true/false; массивы (array) — набор значений; объекты (object) — экземпляры классов; NULL — отсутствие значения; ресурсы (resource) — ссылки на внешние ресурсы (файлы, подключения к БД). PHP является языком с динамической типизацией — тип переменной определяется по значению.
4. Условные операторы: if, else, elseif. Разветвляющиеся алгоритмы
Условные операторы реализуют разветвляющиеся алгоритмы — выполнение разных блоков кода в зависимости от условия. if — выполняет код, если условие истинно. else — выполняет код, если условие ложно. elseif — добавляет дополнительную проверку. Операторы сравнения: == (равно), != (не равно), === (строго равно, с проверкой типа), !== (строго не равно), > (больше), < (меньше), >= (больше или равно), <= (меньше или равно). Логические операторы: && (И), || (ИЛИ), ! (НЕ). Тернарный оператор: условие ? значение1 : значение2 — сокращенная форма if-else.
5. Оператор switch-case (множественный выбор)
switch-case используется для множественного выбора, когда нужно сравнить одну переменную с несколькими значениями. Это альтернатива множественным elseif. Синтаксис: switch(переменная) { case значение1: код; break; case значение2: код; break; default: код по умолчанию; }. break прерывает выполнение, default выполняется если ни один case не подошел. switch удобен для проверки дней недели, месяцев, статусов.
6. Циклы в PHP: for, while, do-while, foreach. Разветвляющиеся циклы
Циклы — это управляющие конструкции, которые позволяют многократно выполнять один и тот же блок кода. Разветвляющиеся циклы — это циклы, внутри которых используются условные операторы (if, break, continue) для изменения хода выполнения.
- for — используется когда известно точное количество повторений: for(инициализация; условие; шаг) { код }
- while — выполняется пока условие истинно, количество повторений неизвестно: while(условие) { код }
- do-while — сначала выполняет код, потом проверяет условие (минимум 1 раз): do { код } while(условие);
- foreach — специальный цикл для перебора массивов: foreach($array as $value) или foreach($array as $key => $value).
Управляющие операторы внутри циклов: break — досрочно прерывает цикл; continue — пропускает текущую итерацию и переходит к следующей.
7. Вложенные циклы и операторы break/continue
Вложенные циклы — это когда один цикл находится внутри другого. Внешний цикл выполняется медленнее, внутренний — быстрее. Применяются для работы с многомерными массивами, таблицами, матрицами. break прерывает выполнение текущего цикла. Если нужно прервать внешний цикл, используется break с числом: break 2; continue пропускает текущую итерацию цикла. continue 2; пропускает итерацию внешнего цикла.
8. Массивы в PHP: индексированные и ассоциативные
Массив — это структура данных, которая хранит несколько значений под одним именем. Доступ к элементам осуществляется по индексу или ключу.
Индексированные массивы — ключи — числа от 0. Создание: $colors = ["красный", "зеленый", "синий"]; или $colors = array("красный", "зеленый", "синий"); Доступ: $colors[0] — "красный".
Ассоциативные массивы — ключи — строки. Создание: $user = ["name" => "Анна", "age" => 25, "city" => "Москва"]; Доступ: $user["name"] — "Анна".
Многомерные массивы — массивы внутри массивов. Например, таблица: $matrix = [[1,2],[3,4]]; Доступ: $matrix[0][1] — 2.
9. Основные функции для работы с массивами
Основные функции для массивов: count($arr) — количество элементов; array_push($arr, $value) — добавить в конец; array_pop($arr) — удалить последний; array_shift($arr) — удалить первый; array_unshift($arr, $value) — добавить в начало; array_merge($arr1, $arr2) — объединить массивы; in_array($value, $arr) — проверить наличие значения; array_keys($arr) — получить все ключи; array_values($arr) — получить все значения; sort($arr) — сортировка по возрастанию; rsort($arr) — сортировка по убыванию; asort($arr) — сортировка ассоциативного массива по значениям; ksort($arr) — сортировка ассоциативного массива по ключам; print_r($arr) — вывести массив для отладки.
10. Строки в PHP: определение и основные операции
Строка — это последовательность символов. Строки создаются в одинарных или двойных кавычках. Двойные кавычки обрабатывают переменные внутри строки (интерполяция), одинарные — нет. Конкатенация (объединение) строк выполняется через оператор точку (.): $str1 . $str2. Основные функции: strlen($str) — длина строки; strpos($str, $search) — позиция первого вхождения (возвращает false если не найдено); substr($str, start, length) — извлечение подстроки; str_replace("что", "на что", $str) — замена; strtolower($str) / strtoupper($str) — приведение к нижнему/верхнему регистру; trim($str) — удаление пробелов в начале и конце; explode("разделитель", $str) — разбить строку в массив; implode("разделитель", $arr) — объединить массив в строку.
11. Суперглобальные массивы ($_GET, $_POST, $_SERVER, $_SESSION)
Суперглобальные массивы — это встроенные массивы PHP, доступные в любой области видимости.
$_GET — данные из URL (метод GET). Видны в адресной строке, ограничение по длине. Пример: page.php?id=5 → $_GET['id'] = 5.
$_POST — данные из тела HTTP-запроса (метод POST). Не видны в URL, подходят для паролей и больших объемов данных.
$_SERVER — информация о сервере и окружении (IP-адрес, браузер, метод запроса). $_SERVER['REQUEST_METHOD'] — метод запроса (GET/POST).
$_SESSION — данные сессии (сохраняются между страницами для одного пользователя). Требует session_start().
$_COOKIE — данные из куки-файлов браузера.
$_FILES — информация о загруженных файлах.
12. Функции в PHP: определение, параметры, возврат значений
Функция — это именованный блок кода, который выполняет определенную задачу и может быть вызван многократно. Определение: function имяФункции(параметры) { код; return значение; }. Параметры — переменные, которые передаются в функцию. Значения по умолчанию: function greet($name = "Гость") { ... }. return — возвращает значение из функции и прекращает её выполнение. Функции могут вызывать другие функции. Встроенные функции: strlen(), count(), mysqli_connect() и др.
13. Работа с базами данных в PHP (mysqli)
mysqli — это расширение PHP для работы с MySQL. Процедурный стиль: mysqli_connect(сервер, пользователь, пароль, БД) — подключение; mysqli_query($link, $sql) — выполнение запроса; mysqli_fetch_array($result) — извлечение строки как массива; mysqli_fetch_assoc($result) — как ассоциативного массива; mysqli_num_rows($result) — количество строк в результате; mysqli_affected_rows($link) — количество затронутых строк (INSERT, UPDATE, DELETE); mysqli_insert_id($link) — ID последней вставленной записи; mysqli_error($link) — текст ошибки; mysqli_close($link) — закрытие соединения. Для SELECT используется while($row = mysqli_fetch_assoc($result)) для перебора всех строк.
14. Основные SQL-запросы в PHP: SELECT, INSERT, UPDATE, DELETE
SELECT — выборка данных: "SELECT * FROM table WHERE условие". INSERT — добавление записи: "INSERT INTO table (col1, col2) VALUES ('val1', val2)". UPDATE — обновление: "UPDATE table SET col = value WHERE id = 1". DELETE — удаление: "DELETE FROM table WHERE id = 1". Значения нужно экранировать. WHERE — условие фильтрации. ORDER BY — сортировка (ASC — по возрастанию, DESC — по убыванию). LIMIT — ограничение количества записей.
15. Обработка ошибок: try-catch и исключения
Исключения (Exceptions) — это механизм обработки ошибок в PHP. try — блок кода, где может возникнуть ошибка. throw — выбрасывает исключение с сообщением. catch — перехватывает исключение и обрабатывает его. finally — выполняется всегда (необязательно). Пример: try { if ($b == 0) throw new Exception("На ноль делить нельзя"); $c = $a / $b; } catch (Exception $e) { echo "Ошибка: " . $e->getMessage(); }. Это позволяет избежать остановки скрипта при ошибке.
16. Разветвляющиеся алгоритмы: понятие и примеры в PHP
Разветвляющийся алгоритм — это алгоритм, в котором в зависимости от условия выполняется та или иная последовательность действий. В PHP разветвления реализуются с помощью: if-else (два варианта); if-elseif-else (много вариантов); switch-case (множественный выбор по одному значению); тернарного оператора (условие ? значение1 : значение2). Разветвления могут быть вложенными — когда внутри одного условия находится другое условие. Также разветвления используются внутри циклов для изменения хода выполнения (break, continue).
17. Итерационные алгоритмы (циклы): понятие и виды
Итерационный алгоритм — это алгоритм, в котором определенная последовательность действий выполняется многократно (циклически). В PHP используются 4 типа циклов: for — для фиксированного числа итераций; while — для повторения пока условие истинно; do-while — гарантирует хотя бы одно выполнение; foreach — специально для перебора массивов. Каждый цикл имеет: инициализацию (начальные значения), условие продолжения, тело цикла (повторяемые действия), шаг (изменение переменных). Итерационные алгоритмы применяются для обработки массивов, перебора записей из БД, вывода таблиц и списков.
18. Рекурсия в PHP: понятие и применение
Рекурсия — это вызов функцией самой себя. Рекурсивная функция обязательно должна иметь условие выхода (базовый случай), чтобы остановить бесконечные вызовы. Применяется для обхода деревьев, вложенных массивов, вычисления факториала, построения меню с неограниченной вложенностью. Пример: function factorial($n) { if ($n <= 1) return 1; else return $n * factorial($n - 1); }. Недостаток: при глубокой рекурсии может переполниться стек вызовов.
19. Включение файлов: include, require, include_once, require_once
Для подключения файлов в PHP используются: include — подключает файл, при ошибке выдает предупреждение (скрипт продолжает работу); require — подключает файл, при ошибке останавливает скрипт (фатальная ошибка); include_once и require_once — подключают файл только один раз, даже если вызывать несколько раз. Это удобно для подключения функций, классов, конфигурации, шаблонов. Путь к файлу может быть относительным или абсолютным.
